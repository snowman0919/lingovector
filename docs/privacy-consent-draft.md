# Privacy Consent Draft

이 문서는 Lingovector 학교 내부 베타용 개인정보 동의 문구 초안입니다. 최종 베타 운영 전 학교/운영자/법무 검토가 필요합니다. 이 문서는 법률 자문이 아닙니다.

## 개인정보 수집 및 이용 동의

Lingovector는 로그인과 학습 기능 제공을 위해 Google account identifier, 이메일, 이름, 프로필 이미지, 이메일 인증 여부, 학습 지문, 문장 분석 기록, 모르는 단어, 단어 친숙도, 발음 점수, 발음 녹음 파일, 영작 제출물, 영작 피드백, 복습 기록, 업로드한 음성 파일, voice profile metadata, 생성된 TTS/audio metadata를 저장할 수 있습니다.

목적은 로그인, 학교 계정 확인, 지문 분석, 개인별 복습, 발음/영작 피드백, 베타 운영, 장애 대응, 보안 확인입니다.

보관 기간은 계정 삭제 또는 필수 동의 철회 전까지를 기본으로 합니다. 법적/운영상 꼭 필요한 최소 기록이 있다면 운영자가 별도 검토 후 안내해야 합니다.

## 개인정보 제3자 제공 또는 외부 서비스 이용 고지/동의

Lingovector는 Google OAuth로 `@dimigo.hs.kr` 학교 계정을 확인합니다. 설정에 따라 optional LLM provider, arXiv, pronunciation provider, storage provider가 사용될 수 있습니다. 실제 provider를 켜기 전 운영자는 어떤 데이터가 외부 서비스로 전송되는지 학생에게 안내해야 합니다.

## 개인정보 처리위탁/처리환경 고지

베타 서비스는 Linux server, Docker Compose, Cloudflare Tunnel, PostgreSQL, local storage 또는 운영자가 승인한 object storage/provider 환경에서 동작할 수 있습니다. 운영자는 서버 접근 권한, 백업, 로그, storage 위치를 최소 권한으로 관리해야 합니다.

## 음성 데이터 및 voice cloning 별도 동의

발음 연습과 voice cloning 테스트를 위해 사용자가 업로드한 음성 샘플, 동의 문구, 동의 버전, 파일 metadata가 저장될 수 있습니다. 학생은 반드시 본인 목소리 또는 명시적 허락을 받은 목소리만 업로드해야 합니다. 복제 음성은 다른 사람을 사칭하는 데 사용할 수 없습니다.

실제 학생 음성 업로드는 동의 gate, 삭제 기능, storage 운영 절차가 검증된 뒤에만 허용해야 합니다.

## 민감할 수 있는 학습/음성 데이터 저장 및 삭제 안내

영작 답안, 발음 기록, 모르는 단어, 음성 샘플은 개인의 학습 상태를 드러낼 수 있습니다. 사용자는 앱의 `개인정보 및 계정` 영역에서 음성 데이터 삭제, 개인정보 제공 동의 철회, 계정 삭제를 요청할 수 있습니다.

필수 동의를 철회하면 Lingovector가 서비스를 계속 제공할 수 없으므로 베타에서는 계정 삭제와 연결된 개인 데이터 삭제 흐름으로 처리합니다.
